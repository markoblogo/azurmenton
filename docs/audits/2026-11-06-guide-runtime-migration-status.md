# Guide Package Delivery And Deferred Runtime Migration

## Verified Implementation

The declarative package compiler and loader are implemented. Maria Serena has been migrated with an exact pre-migration article checksum test. Registration, collection membership and reciprocal guide/place and guide/guide links derive from explicit forward relationships. Package checks run in preflight and before builds.

The owner narrowed this delivery to the existing build path. The Long Afternoon is the first new package: metadata, EN source, FR/IT/UK editorial adaptations and source review in one directory, without a new import/module/registration chain. It retains eleven chapters and ten FAQ questions in every locale. Six real places are linked. Clos du Peyronnet initially had no illustration; the subsequent owner-supplied image was attached through the targeted missing-only importer, completing all six place illustrations without replacing the other five. Its explicit unverified-coordinate exclusion remains. No fictional Lou Paradou place or invented map marker was created.

Nine focused package/Maria Serena/Long Afternoon tests passed on 6 November. Content preflight passed with 138 guides and 663 places. These are local preparation checks, not a deployment receipt. The full release suite, guide-specific browser checks, GitHub CI, exact deployment SHA and public verification remain required release gates. Machine check/browser timings are saved by the existing ignored release and browser receipts; no end-to-end speed multiplier is claimed without a comparable completed run.

The cover was optimized locally to WebP; only this asset's derivatives are generated, not the complete image library. The package records existing public asset paths rather than duplicating media into another storage system. Future illustration passes use the existing targeted place-ID update path and the normal build.

Measured image pass: 2,421 ms for the two new derivatives; source illustration 2,756,590 bytes, optimized cover 318,738 bytes. Full unit suite: 591 passed. The first normal local build hit an OS port-binding prohibition; the documented Webpack fallback built successfully in 331,474 ms. The guide-specific browser pass then confirmed four locales, six decoded images per locale and no overflow at 360/390/768/1440 px. A cold-image timeout was resolved on an isolated rerun. The wider browser suite also exposed an expired hard-coded event fixture and an old guide cover's loading assumption; the tests now select the current month's filtered event and explicitly scroll/wait for that cover. No production event or guide display behavior was changed for those test repairs.
