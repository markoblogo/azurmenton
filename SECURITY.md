# Security policy

Please do not open a public issue for a suspected vulnerability or expose booking data, calendar URLs, API keys, email contents, or personal information in a report.

Use GitHub's **Security → Report a vulnerability** flow for this repository. Include the affected route, impact, reproduction steps, and the smallest useful proof. Redact secrets and guest data.

Supported security updates target the current `main` branch and the production deployment at [azurmenton.com](https://azurmenton.com). Operational booking disputes and content corrections belong in the normal contact or issue flow rather than security reporting.
